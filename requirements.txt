# Python dependencies for Frontier Counts (replaces environment.yml).
#
# Single environment for everything: the application, the test suite, the
# documentation site and local development tools - the same scope as the
# previous conda environment.
#
# Target: Python 3.9 on Linux x86_64 (python:3.9-slim). Every package below has a
# binary wheel for that target, so no compiler is needed in the image. Also
# installs on Windows with Python 3.9 for local development.
#
# Install:
#   python -m venv venv
#   source venv/bin/activate          # Windows: venv\Scripts\activate
#   pip install --no-deps -r requirements.txt
#
# This file is a full lock: transitive dependencies are pinned too, so that the
# environment is reproducible. Versions match the previous conda environment
# except where noted with "CHANGED".
#
# Why --no-deps: pandera 0.13.4 on PyPI declares pandas>=1.2.0, but the code
# requires pandas 1.1.4 (with 1.2.x, 30 of 281 tests fail on FloatingArray/pd.NA
# behaviour changes). conda-forge's pandera build allowed this pair; --no-deps
# installs exactly the pins below without pip enforcing pandera's metadata.
# Because of this, `pip check` reports one expected warning:
#   pandera 0.13.4 has requirement pandas>=1.2.0, but you have pandas 1.1.4.
